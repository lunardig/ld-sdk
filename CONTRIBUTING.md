# Contributing

Thank you for helping build Lunar Dig.

## Contributor agreement

Before we can accept a contribution, you (or, if you contribute on behalf of an
employer or other organization, that organization) must sign the Lunar Dig contributor
agreement, a [Harmony Contributor Agreement](https://www.harmonyagreements.org/), version 1.0:

- **Individual** or **Entity** version, as applies to you;
- a **copyright license** to ioMetics LC: you keep the copyright in your contribution;
- a **patent license** covering your contribution;
- **outbound option five**: ioMetics LC may license your contribution under any license,
  in addition to the license the project uses when you submit it. Lunar Dig needs this
  because the engine is under the Functional Source License, whose versions become
  Apache-2.0 after two years, and because ioMetics LC offers commercial licenses.

To get the agreement and sign it, write to the Software Licensing Administrator,
ioMetics LC, licensing@iometics.com, and return the completed agreement before your first
pull request is merged. You sign once; it
covers all Lunar Dig repositories.

## This repository's license

Apache-2.0; see `LICENSE` and `NOTICE`. Engine binaries in releases are under the engine's own license (`engine/NOTICE.md` in a release).

## How to contribute

Open an issue or a pull request against `main`. Keep changes focused, explain why, and
run the tests the README lists. Anything that changes the engine's behavior needs a
conformance vector and an entry in the relevant LD-PEC specification.
